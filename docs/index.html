아직 기록이 없습니다

docs/data/daily.json 의 daily 배열에 하루 한 줄씩 넣으면 채워집니다.

{ "date": "2026-09-04", "admob": 4200, "iap": 11000, "ads": 30000 }

구글플레이에 찍힌 각국 통화를 그대로 넣어도 됩니다 — 그날 환율로 원화 환산합니다.

{ "date": "2026-09-04",
  "iap": { "KRW": 11000, "USD": 8.97, "JPY": 600 },
  "admob": 4200, "ads": 30000 }

터미널이 편하면:

python3 tools/add.py 2026-09-04 --admob 4200 --ads 30000 \
    --iap KRW:11000 USD:8.97 JPY:600

화면이 어떻게 보이는지 먼저 확인하려면 데모 데이터로 보기.

원장

입력한 값 그대로와, 거기서 더해진 값. 단위는 원.

세 숫자는 손으로 입력하고 날짜는 모두 KST 기준입니다. 각국 통화로 넣으면 그날의 ECB 고시환율로 원화 환산합니다(주말·공휴일은 직전 영업일). 상단의 인앱 수수료 반영은 인앱매출에서 스토어 수수료 15%를 뗄지를 정하며, 히어로·타일·두 차트·원장에 한꺼번에 걸립니다 — 차트마다 따로 두면 화면 안에서 숫자가 서로 안 맞습니다. 체크를 풀면 구매자가 결제한 총액 그대로가 됩니다. 원장에서 *가 붙은 칸은 입력값을 그대로 쓴 게 아니라 환산·수수료 계산을 거친 값이며, 올려두면 결제 원통화부터 적용 환율, 수수료 공제까지 한 줄로 보입니다. 수수료율은 config.json에서 바꿉니다.
