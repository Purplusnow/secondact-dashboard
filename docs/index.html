데모 데이터입니다 — 실제 기록이 아닙니다. 실제 데이터 보기

아직 기록이 없습니다

docs/data/daily.json 의 daily 배열에 하루 한 줄씩 넣으면 채워집니다.

{ "date": "2026-09-04", "admob": 4200, "iap": 11000, "ads": 30000 }

구글플레이에 찍힌 각국 통화를 그대로 넣어도 됩니다 — 그날 환율로 원화 환산합니다.

{ "date": "2026-09-04",
  "iap": { "KRW": 11000, "USD": 8.97, "JPY": 600 },
  "admob": 4200, "ads": 30000 }

터미널이 편하면:

python3 tools/add.py 2026-09-04 --admob 4200 --ads 30000 \
    --iap KRW:11000 USD:8.97 JPY:600

화면이 어떻게 보이는지 먼저 확인하려면 데모 데이터로 보기.

일별

위쪽이 그날 들어온 돈(광고매출 + 인앱매출), 아래쪽이 그날 나간 마케팅비. 흰 선은 그날의 손익.

누적

첫 기록일부터 계속 더한 값. 굵은 선(누적 손익)이 0을 넘은 날이 마케팅비를 다 회수한 날입니다.

원장

입력한 값 그대로와, 거기서 더해진 값.

세 숫자는 손으로 입력합니다. 각국 통화로 넣으면 그날의 ECB 고시환율로 원화 환산하고 (주말·공휴일은 직전 영업일 환율), 인앱매출에서 스토어 수수료 15%를 뗀 값을 씁니다. 원장에서 *가 붙은 칸은 환산된 값이며, 올려두면 원래 통화와 적용 환율이 보입니다. 수수료율은 config.json에서 바꿉니다.
